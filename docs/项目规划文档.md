# AI饮食识别与健康建议小程序项目规划文档

## 一、项目基本信息

### 1.1 项目名称
AI饮食识别与健康建议小程序（AI Food Recognition & Health Advisor）

### 1.2 项目类型
软件应用开发类 · 微信小程序

### 1.3 项目定位
基于人工智能技术的智能化饮食分析工具，为用户提供食物识别、营养计算、健康建议的一站式服务。

---

## 二、项目概述

### 2.1 项目背景

随着我国经济社会快速发展，人民生活水平显著提高，健康饮食意识日益增强。然而，**当代大学生和上班族普遍面临以下困境**：

| 群体特征 | 核心痛点 |
|---------|---------|
| 时间紧张 | 课业/工作繁忙，无暇计算每日营养 |
| 知识匮乏 | 缺乏专业营养学知识，难以判断饮食均衡性 |
| 习惯随性 | 饮食随意性强，长期营养摄入不均衡 |
| 改善困难 | 虽有改善意愿，但缺乏科学指导途径 |

**市场需求分析**：
- 根据《2024年中国健康管理行业发展报告》，我国健康饮食市场规模年增长率达23.5%
- 艾媒咨询数据显示，2024年健康管理小程序用户规模突破3.2亿
- 大学生群体对健康类应用接受度高，具备较强的数字化健康管理需求

本项目正是基于上述社会需求和市場机遇，通过AI技术降低营养管理的门槛，让每个人都能轻松实现科学饮食。

### 2.2 项目简介

**AI饮食识别与健康建议小程序**是一款基于微信小程序的智能化饮食分析工具。

**核心交互模式：聊天框式对话交互**

用户通过自然语言对话与AI助手交流，上传食物照片后，系统将自动完成：

1. **食物识别** - AI大模型精准识别食物种类
2. **营养计算** - 自动估算热量、蛋白质、维生素等营养成分
3. **缺口分析** - 对比当日摄入与推荐摄入量，分析营养缺口
4. **智能建议** - 根据分析结果给出个性化饮食补充方案
5. **健康指导** - 结合用户习惯输出作息、运动、饮水等综合建议

**产品特色**：
- 创新的聊天式交互设计，让健康管理更自然、更友好
- AI驱动的智能识别，告别手动输入的繁琐
- 每日饮食报告，数据化呈现健康状况
- 个性化建议，针对性解决营养缺口问题

#### 3.2.2 功能详细描述

**F1：食物拍照识别**

- 用户点击拍照按钮，调用相机拍照
- 支持从相册选择已有图片
- 上传图片后，AI模型进行图像识别
- 返回识别结果：食物名称、置信度、可信区间
- 用户可确认或修改识别结果
- 识别完成后自动计入当日饮食记录

**F3：每日营养汇总**

- 自动累计当日所有饮食记录
- 按餐次分类展示（早餐、午餐、晚餐、零食）
- 实时显示各项营养素摄入进度
- 与用户个人推荐值对比
- 超量/不足有明显视觉提示

**F5：智能饮食推荐**

- 基于当日营养缺口分析
- 推荐含缺失营养素丰富的食物
- 考虑用户饮食偏好和忌口
- 给出具体的食物清单和份量建议
- 支持一键添加到明日饮食计划

**多模态大语言模型选型说明：**

- **统一接口**：图像识别和对话生成使用同一API，简化开发流程
- **上下文理解**：模型可理解对话历史，提供连贯的多轮交互体验
- **智能分析**：不仅识别食物种类，还能分析烹饪方式、估算份量
- **个性化建议**：结合用户档案和饮食历史，生成个性化营养建议
- **成本优化**：减少API调用次数，降低整体运营成本

#### 5.2.3 营养计算模块

**计算逻辑**：

1. 识别结果中的营养成分数据
2. 根据份量进行换算
3. 累加到当日总量
4. 与用户个人推荐值对比
5. 计算各项营养素缺口/超量

**推荐摄入计算**：

```javascript
// 基础代谢率 (BMR) - Mifflin-St Jeor公式
function calculateBMR(weight, height, age, gender) {
  if (gender === 1) {  // 男性
    return 10 * weight + 6.25 * height - 5 * age + 5;
  } else {  // 女性
    return 10 * weight + 6.25 * height - 5 * age - 161;
  }
}

// 每日总消耗 (TDEE)
function calculateTDEE(bmr, activityLevel) {
  const multipliers = [1.2, 1.375, 1.55, 1.725, 2.0];
  return Math.round(bmr * multipliers[activityLevel - 1]);
}

// 目标摄入
function calculateTarget(tdee, goal) {
  switch (goal) {
    case 'lose_weight': return tdee * 0.8;  // 减脂
    case 'maintain': return tdee;           // 维持
    case 'gain': return tdee * 1.1;         // 增肌
    default: return tdee;
  }
}
```

## 六、UI/UX设计方案

### 6.1 设计原则

#### 6.1.1 设计理念

**核心理念：自然、智能、温暖**

- **自然**：交互设计模拟人与人之间的对话，降低学习成本
- **智能**：AI能力融入每个交互环节，让用户感受到智能便利
- **温暖**：视觉设计传递关怀，消除健康管理带来的焦虑感

#### 6.1.2 设计原则

| 原则 | 描述 | 应用示例 |
|-----|-----|---------|
| 渐进式披露 | 信息逐层展示，避免信息过载 | 识别结果先展示关键信息，详细成分点击展开 |
| 即时反馈 | 每个操作都有明确反馈 | 识别中显示加载动画，结果以动效呈现 |
| 容错设计 | 允许错误，提供恢复途径 | 识别错误可手动修改，误删可恢复 |

async function recognizeFood(imagePath) {

#### 7.2.2 营养缺口分析算法

```javascript
// 营养缺口分析
function analyzeNutrientGaps(dailyIntake, dailyTargets) {
  const gaps = {};
  const surplus = {};
  
  for (const nutrient in dailyTargets) {
    const intake = dailyIntake[nutrient] || 0;
    const target = dailyTargets[nutrient];
    const ratio = intake / target;
    
    if (ratio < 0.9) {
      gaps[nutrient] = {
        intake,
        target,
        gap: target - intake,
        severity: ratio < 0.5 ? 'high' : 'medium'
      };
    } else if (ratio > 1.1) {
      surplus[nutrient] = {
        intake,
        target,
        amount: intake - target,
        severity: ratio > 1.3 ? 'high' : 'medium'
      };
    }
  }
  
  return { gaps, surplus };
}
```

#### 7.2.3 智能推荐算法

```javascript
// 基于缺口生成推荐
function generateRecommendations(gaps, userPreferences, nutrientDatabase) {
  const recommendations = [];
  
  for (const nutrient in gaps) {
    const gapInfo = gaps[nutrient];
    
    // 查找富含该营养素的食物
    const richFoods = nutrientDatabase
      .filter(food => food.nutrients[nutrient] > food.nutrientsThreshold)
      .filter(food => !userPreferences.allergies.includes(food.name))
      .sort((a, b) => b.nutrients[nutrient] - a.nutrients[nutrient])
      .slice(0, 5);
    
    // 生成推荐
    for (const food of richFoods) {
      const suggestedAmount = Math.ceil(
        gapInfo.gap / food.nutrients[nutrient] * food.standardPortion
      );
      
      recommendations.push({
        nutrient,
        food: food.name,
        amount: suggestedAmount,
        reason: `补充${nutrient} ${gapInfo.gap.toFixed(0)}mg`,
        priority: gapInfo.severity === 'high' ? 1 : 2
      });
    }
  }
  
  return recommendations.sort((a, b) => a.priority - b.priority);
}
```
