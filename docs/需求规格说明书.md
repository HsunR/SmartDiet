## 一、引言

### 1.1 编写目的

本文档详细描述AI饮食识别与健康建议小程序的功能需求和非功能需求，作为项目开发、测试和验收的基准依据。

**预期读者**：
- 项目开发人员
- 测试工程师
- 产品经理
- 项目评审人员

### 1.2 项目背景

随着人们健康意识的提升，科学饮食管理需求日益增长。本项目旨在通过AI技术降低营养管理的门槛，为用户提供便捷、智能的饮食分析服务。

### 1.3 术语定义

| 术语 | 缩写 | 定义 |
|-----|-----|-----|
| 用户 | User | 使用小程序的最终用户 |
| AI营养师 | AI Nutritionist | 系统中的智能对话助手 |
| 饮食记录 | Food Record | 用户上传的食物识别记录 |
| 营养缺口 | Nutrient Gap | 实际摄入与推荐摄入的差值 |
| 每日报告 | Daily Report | 当日饮食营养汇总报告 |
| TDEE | Total Daily Energy Expenditure | 每日总能量消耗 |
| BMR | Basal Metabolic Rate | 基础代谢率 |

**营养计算公式**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              营养计算公式                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. 基础代谢率 (BMR) - Mifflin-St Jeor公式                                  │
│     ────────────────────────────────────────────────────────────────────── │
│     男性: BMR = 10 × 体重 + 6.25 × 身高 - 5 × 年龄 + 5                      │
│     女性: BMR = 10 × 体重 + 6.25 × 身高 - 5 × 年龄 - 161                    │
│                                                                             │
│  2. 每日总消耗 (TDEE)                                                       │
│     ────────────────────────────────────────────────────────────────────── │
│     TDEE = BMR × 活动系数                                                   │
│                                                                             │
│     活动系数:                                                               │
│     • 久坐(很少运动): 1.2                                                   │
│     • 轻度活动(每周1-3次运动): 1.375                                        │
│     • 中度活动(每周3-5次运动): 1.55                                         │
│     • 高度活动(每周6-7次运动): 1.725                                        │
│     • 极高度活动(体力劳动/专业运动员): 2.0                                  │
│                                                                             │
│  3. 目标热量                                                                │
│     ────────────────────────────────────────────────────────────────────── │
│     • 减脂: 目标热量 = TDEE × 0.8                                          │
│     • 维持: 目标热量 = TDEE                                                 │
│     • 增肌: 目标热量 = TDEE × 1.1                                          │
│                                                                             │
│  4. 宏量营养素分配                                                          │
│     ────────────────────────────────────────────────────────────────────── │
│     • 蛋白质: 目标热量 × 20% ÷ 4 = 克数                                    │
│     • 碳水: 目标热量 × 50% ÷ 4 = 克数                                      │
│     • 脂肪: 目标热量 × 30% ÷ 9 = 克数                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

**营养缺口判定标准**：

| 营养素 | 缺乏阈值 | 充足范围 | 超量阈值 |
|-------|---------|---------|---------|
| 热量 | <80%目标 | 80%-110%目标 | >110%目标 |
| 蛋白质 | <80%目标 | 80%-120%目标 | >120%目标 |
| 碳水 | <70%目标 | 70%-120%目标 | >120%目标 |
| 脂肪 | <70%目标 | 70%-110%目标 | >110%目标 |
| 维生素C | <60%推荐 | 60%-200%推荐 | >200%推荐 |
| 钙 | <60%推荐 | 60%-150%推荐 | >150%推荐 |
| 铁 | <60%推荐 | 60%-180%推荐 | >180%推荐 |
