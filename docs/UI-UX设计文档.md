## 一、设计概述

### 1.1 设计理念

**核心理念：自然、智能、温暖**

| 理念 | 描述 | 设计体现 |
|-----|-----|---------|
| 自然 | 交互设计模拟人与人之间的对话，降低学习成本 | 聊天式主界面、自然语言交互 |
| 智能 | AI能力融入每个交互环节，让用户感受到智能便利 | 智能识别、智能推荐、智能回复 |
| 温暖 | 视觉设计传递关怀，消除健康管理带来的焦虑感 | 柔和配色、友好文案、鼓励性反馈 |

### 1.2 设计原则

| 原则 | 描述 | 应用示例 |
|-----|-----|---------|
| 渐进式披露 | 信息逐层展示，避免信息过载 | 识别结果先展示关键信息，详细成分点击展开 |
| 即时反馈 | 每个操作都有明确反馈 | 识别中显示加载动画，结果以动效呈现 |
| 容错设计 | 允许错误，提供恢复途径 | 识别错误可手动修改，误删可恢复 |
| 个性化 | 根据用户特征提供定制体验 | 新用户引导完善信息，根据目标调整推荐 |
| 一致性 | 保持视觉和交互的一致性 | 统一的组件样式、操作逻辑 |

## 四、交互设计

### 4.1 手势交互

| 手势 | 场景 | 行为 |
|-----|-----|-----|
| 点击 | 按钮、卡片、列表项 | 触发对应操作 |
| 长按 | 图片消息 | 保存图片到相册 |
| 下拉 | 聊天页面 | 刷新消息 |
| 上拉 | 列表页面 | 加载更多 |
| 左滑 | 记录列表项 | 显示删除按钮 |
| 双击 | 图片 | 放大查看 |

### 4.2 动画效果

| 场景 | 动画类型 | 时长 | 缓动函数 |
|-----|---------|-----|---------|
| 页面切换 | 滑入/滑出 | 300ms | ease-in-out |
| 消息出现 | 淡入+上移 | 200ms | ease-out |
| 识别完成 | 缩放弹入 | 400ms | spring |
| 进度更新 | 宽度渐变 | 500ms | ease-in-out |
| 按钮点击 | 缩放 | 100ms | ease-out |

### 4.3 反馈设计

| 操作 | 反馈类型 | 反馈内容 |
|-----|---------|---------|
| 点击按钮 | 视觉 + 触觉 | 按钮缩放 + 轻微震动 |
| 识别成功 | 视觉 + 音效 | 成功动画 + 提示音 |
| 识别失败 | 视觉 | 错误提示弹窗 |
| 记录保存 | 视觉 | Toast提示"已记录" |
| 网络错误 | 视觉 | 错误提示弹窗 + 重试按钮 |
